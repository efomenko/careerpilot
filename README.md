# CareerPilot — AI Job Search Copilot

CareerPilot is a portfolio project designed to help job seekers
organize career evidence, assess their fit for job opportunities,
prepare tailored application drafts, and track applications.

## Core principle

CareerPilot must never invent career facts, achievements, metrics,
responsibilities, or results.

Career evidence, generated drafts, and user approval remain separate.

## Current status

**Phase:** Repository foundation

The initial version contains a minimal HTML, CSS, and JavaScript
application. Product features will be implemented incrementally.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript (ES modules)
- Git and GitHub
- Browser localStorage (planned)

## Run locally

1. Clone the repository.
2. Open the repository in VS Code.
3. Start a local static server, for example using the Live Server
   extension.
4. Open the served `index.html` page in your browser.

A local HTTP server is recommended for reliable ES module loading.

## Documentation

See the `docs/` directory for the product requirements,
user stories, roadmap, technical design, testing strategy,

## Planned capabilities

- Career profile and employment history
- Evidence-backed achievement library
- Job description and requirement management
- Explainable job-fit assessment
- Editable, evidence-grounded application drafts
- Application tracking
- Local persistence and JSON backup/restore

AI integration is planned for a later stage and will use a backend.

## Project status

This project is under active development. Features should not be
considered implemented until they have been tested.
